# 供应商选择与采购

采购建议不是购买授权。价格、库存、条款、线路和测试 IP 都会变化；每次比较都记录来源 URL 与观察时间。

面向新手时先执行 [guided-interview.md](guided-interview.md)。询问用户可观察的需求，不要求用户先理解 ASN、线路商品名、虚拟化或协议内部；这些技术映射和实时事实由 agent 负责解释、搜索和举证。

## 需求卡

只追问会改变排名的信息：

- 客户端所在国家/城市、家庭 ISP、移动运营商、IPv4/IPv6 情况。
- 用户要的是互联网出口、弱网/移动网络适应、远程私网还是业务解锁；协议、传输和端口应在客户端与网络事实明确后由 agent 映射，已知偏好再单独记录。
- 设备数、并发、持续与峰值速度、上下行对称性、月流量。
- 需要真实验收的网站/应用及成功定义：可达、登录、播放、API 或支付。
- 可接受中断、恢复时间、是否需要跨供应商/地区的第二节点。
- 公网 IP、NAT 映射、端口、rDNS、快照、VNC/console、rescue/reinstall、API 等要求。
- 月费、设置费、税费、币种、最短账期、退款窗口和续费涨价容忍度。
- 司法辖区、数据处理、AUP/TOS 和 abuse 响应要求。

使用 [../assets/requirements-card.md](../assets/requirements-card.md) 记录。

## 先过硬门禁

任一适用门禁失败即淘汰；关键项未知则挂起为 `unverified`：

1. **用途允许**：当前 AUP/TOS 或供应商书面答复不禁止预期的个人、认证、非公开 VPN/代理流量。
2. **协议可达**：所需公网地址/NAT 映射、TCP/UDP、端口和客户端运营商路径可用。HY2 必须单独确认 UDP/QUIC。
3. **容量合适**：端口共享/独享、FUP、限速、连接数、月流量、单双向计费、重置日和超额行为满足需求并有余量。
4. **可恢复**：控制台/VNC、重装或 rescue、凭据恢复和有效支持渠道可用。
5. **风险可接受**：账期、退款、续费、支付、司法辖区和供应商连续性符合用户风险边界。

NAT VPS 并非必然不合格；只有映射数量、UDP、地址稳定性或恢复方式无法满足声明需求时才淘汰。

## 证据类型

每项结论标注为：

- `seller claim`：广告、套餐页、条款、工单或面板原文。
- `confirmed fact`：当前一手资料或针对精确目标的可复现实测。
- `third-party observation`：注明服务和时间的 BGP、路由、位置或信誉观察。
- `inference`：由已列证据推导的工程判断。
- `unverified`：缺失、模糊、过期、仅测试 IP 或购买前无法验证。

## 候选比较

只对通过硬门禁的候选评分。权重由用户选择，可包含：

- 真实客户端运营商的路由质量与稳定性。
- 协议性能、端口和流量余量。
- 实际分配 IP 的业务适配与风险。
- 控制台、备份、支持和可观测性。
- 供应商、账单、退款与续费风险。
- 计算/磁盘容量和总成本。

不把未知项填成中间分。应解决未知、单列置信度惩罚，或给出分数区间。测试 IP/looking glass 只能初筛；实际分配 IP 必须重新验收。

线路名称只是候选信号：AS9929、CN2/AS4809、CMIN2/AS58807、AS4837、AS4134 或 CMI/AS58453 出现在卖家文案或某次路径中，都不能单独证明用户会获得低延迟。排序必须结合用户真实接入运营商、城市、去程与回程、晚高峰、丢包、抖动和持续吞吐。

## 采购动作

购买前确认：

- 供应商与 SKU，而不是只记录线路宣传名。
- 最终购物车总价、币种、设置费、税费、账期、自动续费和续费价。
- IP 数量、地址类型、端口、流量、镜像与附加选项。
- 退款/换 IP 条件，以及相关产品是否被列为不退款类别。
- 保存条款和订单快照，但不保存账户 Token、密码、付款信息或完整账单身份信息。

新供应商优先选择能覆盖真实网络产品的最短可行试用周期。测试计划过小可能无法代表目标 CPU/端口，测试计划过大则增加不可逆成本。
