# 隐私与 Secret 处理

## 可以分享

- 供应商名称、公开 SKU、公开购买/条款链接、公开测试 IP。
- 带观察时间的公开价格和规格快照。
- 匿名化性能区间、通用架构、测试方法和结论边界。
- 使用 RFC 5737 文档地址、example.com、假 UUID/密钥的模板。

## 不可以分享

- 实际分配的管理/出口 IP、SSH 端口、用户名、主机别名和主机指纹。
- 密码、Token、私钥、UUID、short ID、HY2 password、REALITY private key、统计 API Secret。
- 个人姓名、账户 ID、订单号、付款信息、完整发票、邮箱、电话和家庭位置。
- 个人设备名称、MAC/IMEI、私有域名、家庭公网 IP、个人目录和内部文件路径。
- 能识别个人习惯的完整网站清单、原始日志、逐设备流量和精确时间序列。

## 生成与报告规则

- 用 `<VPS_IP>`、`<SSH_PORT>`、`<ADMIN_USER>`、`<DOMAIN>`、`<UUID>`、`<PUBLIC_KEY>`、`<SHORT_ID>` 和 `<HY2_PASSWORD>` 作为占位符。
- 文档示例 IP 只用 `192.0.2.0/24`、`198.51.100.0/24` 或 `203.0.113.0/24`。
- 生成真实配置时写到用户指定的私有目录，权限 0600；报告只记录“已生成/权限/校验通过”。
- 命令行、shell history、process list 和 CI 日志中不传完整 Secret；优先用受限文件或安全输入。
- 分享前扫描真实 IPv4、家目录、用户名、邮箱、常见 Secret 字段和值。命中后人工判断公开测试 IP 与私人地址的区别。
- 不能只依赖正则：还要人工检查自由文本、截图、压缩包清单、文件元数据和嵌套归档。

分享版的校验器不嵌入任何人的真实隐私值。若维护者需要核对一组已知私人标识，在 skill 目录外建立权限 0600、每行一个值的临时文件，然后运行：

```bash
python3 scripts/validate_distribution.py --canary-file <private-canary-file>
```

校验器会在运行时读取这些值，命中即失败；canary 文件本身不得进入分享目录或压缩包。随机 canary 自测只能证明检测机制工作，不等于已自动识别所有自由文本隐私，发布前仍需人工复核。
