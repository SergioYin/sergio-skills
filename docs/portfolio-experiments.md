# 作品集实验清单（2026-07 起，6 个月弧线）

> 目标：把私有作品变成公共作品，攒"未来三五年上升"的跳槽依据。
> 每个实验统一格式：**产物 / 受众 / 反馈字段 / 判定标准**。一次只跑一个（健哥自己的规矩），每月在晚间复盘里做一次实验中检。
>
> **硬护栏：公司代码、数据、内部文档一行都不碰。** 领域痛点必须匿名化成通用工业软件案例（芯行纪身份合规红线）。所有素材来自个人栈（Hermes、sergio-skills、target-1）。

---

## 第一梯队：已有资产再包装（启动成本最低，2-4 周/个）

### E1. 《我审计了自己 AI 管家的 745 个会话》

- **产物**：一篇方法论文章：怎么从 state.db 挖使用模式、发现了什么（20% 元开销、116 次重复样板、验证纪律失效）、怎么把发现变成 harness 修正（系统指令、skill、反谄媚纪律）。素材已 100% 存在（`hermes-audit-2026-07-06.md`），只差翻译成公开叙述。
- **受众**：即刻 AI 圈 / V2EX / 掘金；英文版可发 X。
- **反馈字段**：每天记一条——有没有真人回应、回应是共鸣还是反驳、有没有人问"怎么做的"。
- **判定**：2 周内出现 ≥1 次实质性技术讨论（不是点赞）→ 继续写系列；零回应 → 换平台再发一次，仍零 → 复盘标题和切入角，不否定内容。
- **为什么第一个做**：它同时展示数据分析、harness 工程、诚实的自我评估——恰好是"会用 AI"和"AI 工程能力"的分界线证据。

### E2. 反谄媚 Harness 开源

- **产物**：小仓库：adversarial-judgment skill + SOUL.md 反谄媚纪律 + 设计文档（激励结构分析：为什么劝模型诚实没用、为什么要把反驳写成成功标准）。附一个真实对照例子。
- **受众**：GitHub + 一篇配套短文。sycophancy 是行业公认痛点，内容有天然钩子。
- **反馈字段**：star / issue / 有没有人真的装了。
- **判定**：30 天 ≥10 star 或 ≥1 个外部 issue → 值得维护；否则归档为作品集展品（展品价值不清零）。

## 第二梯队：共通语言工程（1-2 月/个，治"悟到了说不出"）

### E3. 翻译练习：《工业软件为什么缺领域模型》系列

- **产物**：把 `industrial-software-domain-modeling-critique` skill 里的批判，逐篇翻译成行业词汇——同一个痛点写两遍：一遍你自己的话，一遍用 DDD 术语（bounded context / ubiquitous language / anti-corruption layer）。翻译差值就是你要补的共通语言，写的过程就是学的过程。
- **受众**：即刻/掘金 + 工业软件从业者社区。
- **反馈字段**：有没有工业软件同行说"我们公司也这样"；有没有人纠正你的术语用法（纠正=免费教学）。
- **判定**：3 篇后如果同行认同率为零 → 说明翻译还不对，找一本 DDD 原典精读后再写；有认同 → 继续，这就是你的行业身份标签。

### E4. Demo：需求文档 → 领域模型 + 可跑的篱笆

- **产物**：一个小而完整的公开 demo：agent 读入一份混乱的需求/规格文档，产出领域模型草案 + 可执行的边界校验代码。这是 target-1 道层思想的一个薄公开切片（概念卡 + 篱笆=能跑的代码），不暴露整个 Domain Runtime。
- **受众**：GitHub + 演示视频/GIF。
- **反馈字段**：有没有人 fork/复现；有没有人说"这解决了我的问题"。
- **判定**：这是"领域建模 × Agent 没人信服"的正面回应——**别人不信服论点，只信服 demo**。60 天做不完就砍范围，不弃项。

## 第三梯队：市场校准（与上面并行，几乎零成本）

### E5. JD 逆向工程

- **产物**：读 20 份 JD（Agent 工程师 / AI 应用工程师 / AI+工业软件），提取词汇表和技能矩阵，对照自己打分，产出 gap 表。
- **反馈字段**：哪些词你会做但不会说（翻译问题），哪些真不会（学习问题）——两者的处方完全不同。
- **判定**：产出 gap 表即完成。这直接治"根本不了解 AI 求职市场"。

### E6. 三次真人对话

- **产物**：通过 E1-E4 积累的评论区/社区，约 3 个做 agent 工程或 AI+工业软件的人聊 30 分钟（线上即可）。
- **反馈字段**：你的自我介绍对方能不能听懂；记下**他们**描述这个领域用的词。
- **判定**：3 次完成即成功，不论结论。这是孤独实验和职业实验的合流点。

## 节奏与止损

- 顺序：E1 → E2 → E3 → E4，E5/E6 见缝插针。一次只有一个"当前实验"。
- **停滞协议**（治"一遇困难就停"）：卡住 3 天 = 触发降级——砍一半范围继续，而不是停下。任何实验的最小可交付 = 一篇带真实数据的短文。
- 每月复盘问三个问题：这个月发布了什么？谁回应了？下个月的一个实验是什么？
- 6 个月后盘点：作品集（≥3 个公开产物）+ gap 表 + 3 次对话记录 = 重新评估 C 选项（跳槽）的弹药库。
